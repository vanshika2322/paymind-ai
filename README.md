# 💳 PayMind AI – Payment Decision Engine

PayMind AI is an intelligent system that predicts payment success probability and recommends the best retry method using AI-driven logic.

---

## 🚀 Features

- 🔍 Predicts payment success/failure using Machine Learning
- 🔁 Suggests optimal retry method (UPI, Wallet, etc.)
- 🧠 Provides AI-style explanation for better decision-making
- 📊 Visualizes success vs failure using charts
- ⚡ Fast and user-friendly web interface

---

## 🧠 How It Works

1. User enters payment details  
2. ML model predicts success probability  
3. Decision engine suggests best retry method  
4. AI reasoning layer explains the outcome  

---

## 🛠 Tech Stack

- Python  
- Flask  
- Scikit-learn  
- Pandas  
- HTML, CSS  
- Chart.js

## 🤖 AI Components Used
